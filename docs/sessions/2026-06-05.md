### Imports
- **VIDEO IMPORT**: creates new scene, auto-extracts poster frame (canvas `drawImage` → JPEG data URL), pulls audio onto the // MUSIC row at matching start/duration, mutes the video element so audio plays once
- **VOICEOVER IMPORT**: file picker → new VO segment with auto-measured duration
- **MUSIC IMPORT**: file picker → new music segment with auto-measured duration
- **GRAPHICS IMPORT**: accepts PNG, JPG, SVG, GIF, WebP, AVIF, BMP, ICO + text files; images render via `<img>` in stage with `object-fit: contain`
- **Audio format guard**: `canBrowserPlayAudio()` rejects AIFF / Apple Lossless / unsupported formats with a clear toast
- **Video format guard**: `canBrowserPlayVideo()` rejects MKV / AVI / WMV / FLV
- **No modal popups on import** — files land in timeline, no editor opens
- **Preview accepts `blob:` / `data:` URLs** for imported videos (was only http)
- `object-fit: contain` on stage-video/img and clip-thumb (was cover) — imports letterbox, never crop

### Modals (popups on click)
- **VO segment** → `VOSegmentEditor` with import + Generate VO + remove
- **Music segment** → **new** `MusicSegmentEditor` — mirrors VO exactly with import + **Generate music** button (per-segment, calls Replicate or ElevenLabs Music)
- **Graphic block** → `GraphicOverlayEditor` as a modal popup (was inline)
- **Imported clips** → **new** `ImportedClipPanel` — simplified: preview, title, duration slider, **▤ Re-import**, **✕ Remove clip**. No still/motion generation UI
- **Generated/empty clips** → original `FlowPanel` with still + motion generation
- `sectionHasImportedContent()` detects `blob:` / `data:` URLs to route
- Esc closes all modals (with proper precedence)
- **Delete key** on selected section → `confirmAsk` modal (no native browser `confirm()`)
